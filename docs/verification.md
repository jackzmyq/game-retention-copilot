# 验收记录

验证环境：Windows、Python 3.12；依赖版本见 requirements-lock.txt。分析数据 SHA-256 与 reports/analysis.json 一致。当前记录不包含真实 DeepSeek 成功率或业务提效比例。

## 已验证

- 原始发布者地址可下载 CSV；90,189 行、5 字段，玩家 ID 唯一，关键字段无缺失。
- 分流表与结果表 1:1 关联，原始人数、聚合视图、局数分组及留存返回组合总人数一致。
- SQL 聚合分子分母与独立 Pandas 分组一致；两比例检验与独立 SciPy 列联表卡方检验数值一致。
- Wilson 边界、Newcombe 差异方向、Holm、SRM 假设标签和样本量场景的关键性质经过测试。
- 主分析保留极端记录，排除仅作敏感性检查；D7 差异由 −0.8201pp 变为约 −0.8183pp，未因异常均值悄悄删样本。
- SQL 多语句、DDL/DML、PRAGMA、ATTACH、基础玩家表、系统表、限定库名、扩展加载、文件读取、巨大随机 BLOB、递归查询、CTE 伪装等测试输入被拒绝；测试前后数据库哈希一致。
- 聚合 SELECT 和合法 CTE 可以执行；行数截断及短超时用例得到验证。
- Agent 模拟 provider 完成工具调用 → 执行 → 回传 → 回答闭环；包含错误查询修复案例，以及无证据回答拒绝案例。此项是协议模拟，不是远端真实模型测试。
- Streamlit AppTest 检查默认作品导览及跳转、分析工作区、英文切换、决策沙盘滑块、离线规则演示及两轮聊天；浏览器检查实际图表与页面布局。
- 新增情景测试：人数换算的符号、区间和规模比例一致；容忍边界调整不改变观测结果；改变预期比例不会把未核实假设标为已验证；D1/D7 四种组合与分组留存分子分母一致。
- 浏览器实测：容忍边界从 0.5pp 改为 1.5pp 时，说明从“区间跨越边界”更新为“位于范围内但不代表可上线”，恢复 0.5pp 后说明恢复；窄屏指标卡为两列排列。
- 实时 Agent 历史上下文限制为最多六条 user/assistant 消息；测试验证历史不能引入额外 system 消息，并仍需本轮工具证据。新情景工具经过数值及参数范围测试。

- 来源完整性：原始字节和缓存文件均需匹配审核 SHA-256；人为追加一行后被拒绝，旧来源清单未被覆盖。
- 构建失败保护：在派生表建立后注入计算故障，旧数据库哈希与旧报告均保持不变；暂存目录得到清理。
- 构建一致性：数据库元数据与报告 ID 不匹配时，读取被拒绝；模型回答过程中发生重建时，混合版本回答被拒绝。
- SQL 资源边界：巨量 printf/format 请求被拒绝，负数/超大行数、NaN/超长超时不能绕过限制；单值大小、列数与表达式深度受限。
- 双语简报、默认沙盘与离线证据示例现在由一个命令生成，情景状态使用面向读者的文案。

- HR 交付：导览明确固定数据、可迁移方法、API 状态和 localhost 访问限制；免安装 HTML 无脚本和外部样式依赖，内部导航可解析；阅读包不含运行环境或密钥。
- PDF 交付：确认为两页、关键数字与访问说明可提取；逐页渲染检查中文字体、表格、指标卡、边距及页脚，修正指标卡行距后重新检查。
