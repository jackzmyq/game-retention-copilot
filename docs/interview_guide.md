# 面试讲解与项目演示

## 90 秒讲述

“我围绕游戏运营中的机制改动是否应上线，做了一个留存实验分析和 AI 分析助手。数据来自 Cookie Cats 的公开教学实验，共 90,189 名玩家，比较门槛在第 30 关和第 40 关两种方案。

我先检查玩家粒度、缺失值、去重和关联，再用 SQL 构建留存指标，用 Python 计算两组比例差异和区间。结果是 gate_40 的 D7 留存低约 0.82 个百分点，但我没有直接下‘确定导致流失’的结论：在假设 50:50 时分流比例触发复核，真实预期比例又没有提供。因此我的建议是暂缓全量上线，先核验实验完整性。

我把分析沉淀成中英文交互看板和指标知识库，再用工具调用方式接入 AI 助手。模型只能查聚合视图，回答能展开 SQL 和证据；面对缺少地区或日历字段的问题会说明限制。这个流程可迁移到新手引导或解锁节奏实验，但需要重新获取地区、时区和曝光数据，不能把消除游戏结论套到米哈游产品。”

若尚未配置真实 API，最后一段必须说“实现了可接入的流程，目前验收包括本地查询和协议模拟，真实调用待配置”；不要把离线规则演示说成大模型。

## 3 分钟演示顺序

1. 实验决策页：解释分子分母、−0.82pp、区间、D1 未显著与 SRM 条件；打开分母和检验结果。
2. 决策沙盘页：设 10 万人规模，解释约 −820 人的换算及区间；调整容忍边界，说明不是实际损失、预测或正式非劣效检验。
3. 行为与质量页：解释极端值为什么保留，均值局数差为何大幅变化而 D7 差异稳定；查看四种回访组合，说明不能做召回归因。
4. AI 页：先问“是否上线 gate_40”，展开该消息的工具证据；再问“为什么欧洲上周 DAU 下降”。清楚区分离线规则与真实模型，最近上下文不替代新证据。
5. 切换英文并下载简报，说明国际化需要指标、时区与地区验证。

## 必须能回答的追问

**为什么不继续做流失预测？** 当前累计局数是分流后记录，观察范围甚至有 7/14 天冲突；可能包含 D7 本身或其后行为，拿来预测 D7 会泄漏。没有独立的早期观察窗口就不训练一个看似高 AUC 的模型。

**D7 留存低 0.82%，还是 0.82 个百分点？** 是 19.02% 到 18.20%，绝对差 −0.82 个百分点，相对约 −4.31%。两者不同。

**显著就能上线或回滚吗？** 先检查分流、覆盖、窗口和实验机制，再结合实际效果、护栏与成本。此样本缺少收入护栏和曝光记录，所以建议有条件。

**SRM 是否证明实验失败？** 不是。这里假设 50:50 而未核实，p≈.0086 是在该假设下的偏离程度；筛查阈值 .01 为项目设置。还需要真实预期概率和入组记录，不应为了让 SRM 通过而删玩家。

**D1 未显著可以说无影响吗？** 不可以。未拒绝零差异不代表等效；等效需要预先规定可接受边界并做相应检验。

**为什么多重检验？** 事后同时看 D1、D7 容易挑显著结论；对两项 p 值做 Holm 校正，同时报告原始值。95% 区间仍是逐项区间，并非同时区间；不声称预注册或序贯监控有效。

**局数高的玩家更留存，是不是多引导玩几局就行？** 不一定。累计局数和留存受共同因素影响，而且窗口重叠、分组发生在处理后。需要早期行为日志或新的随机干预来验证机制。

**SQL 做了什么，为什么拆表？** 源数据本来只有一张玩家级表。项目把分流和结果规范化，显式校验 1:1 关联，并创建聚合证据视图。它展示 SQL 建模与口径，不假装获得了真实多源事件日志。

**Agent 和单次问答有何差别？** 模型可选择并多轮调用 schema、指标字典、SQL、统计证据和报告工具，程序实际执行并回传，模型再决定下一步；限制步数并保留轨迹。离线模式是固定规则，另行标注。

**SQL 安全靠 Prompt 吗？** 不。AST 限定单条 SELECT 和视图，SQLite 以只读 URI 打开，authorizer 再限制数据与函数，加行数及执行时间上限。Prompt 解释指标，执行边界由代码落实。测试不能证明对所有攻击都安全。

**如何保证交付结果能复现、不会混用旧数据？** 下载和构建都固定校验原始数据 SHA-256；数据库在暂存位置完成校验后替换，计算失败保留旧结果。数据库和 JSON 有共同的构建 ID，页面与助手会核对，模型回答中途发生重建会拒绝本次输出。多份文件不是一个全局事务，需要如实说明一致性检查的范围。

**如何避免模型幻觉？** 从已执行工具结果回答，统计结果由代码计算，展示证据，拒绝无成功检索的回答，人工复核。仍不宣称完全消除幻觉，也未量化准确率或节省时间。

**为何适合国际化岗位？** 数据质量、实验效果评估、分析自动化与双语沟通可迁移；国际化实测本身尚未实现。未来补充地区、语言、平台、当地日界与曝光，并控制多地区比较和小样本风险。

**用了 AI，你具体做了什么？** 如实说明工具参与了代码生成。面试前亲自跑查询、解释差异公式、修改一个图表或阈值并验证结果，明确自己理解和核验过的部分。不要把尚未掌握的代码说成独立手写。
