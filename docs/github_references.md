## 未照搬的推断

- 不报告事后功效为额外证据；将样本量用于下一次实验的事前规划。
- 不从 D1 与 D7 两个终点推断新鲜感效应消退或增强，缺少按暴露时长测量的纵向证据。
- 不将累计局数分组当作处理前客群，或把回访组合当作召回活动归因。
- 不以观察比例反推“正确的预期分流”来使 SRM 通过；滑块只呈现假设敏感性。
- 不把规模换算称为实际损失、业务收益或预测；区间不包含未来迁移的不确定性。
- 不声称证据展示消除了所有大模型幻觉。

## 本轮分析增量

1. 规模情景：固定历史效果，对假设总体换算人数及区间；导出包含当前假设。
2. 业务容忍边界：比较单指标区间与事后边界，明确不是正式非劣效检验。
3. 分流敏感性：预期比例变化时检查结果如何变化；完整性复核始终保留。
4. 回访组合：同时展示 D1/D7 四种组合，保留两组分母；不是漏斗或机制归因。
5. 极端值解读：指出均值局数差对单条极端记录敏感，但 D7 差异稳定。
6. 可选 AI 层：本地统计、图表和情景导出不依赖 API；真实模式使用有限历史上下文和重新检索的证据。
